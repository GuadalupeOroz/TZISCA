# Vistas por rol

[Documentación](../README.md) · [Inicio](../../README.md)

Interfaces del conjunto **V3** de Figma, organizadas por rol. Los diagramas funcionales se conservan en [diagramas](../diagramas/README.md).

| Rol | PNG disponibles | Inventario |
|---|---|---|
| Cliente | 28 | [Cliente](cliente/README.md) |
| Administrador general | 9 | [Administrador general](administrador/README.md) |
| Recepción y cabinas | 23 | [Recepción y cabinas](recepcion/README.md) |
| Proveedor de tratamiento | 13 | [Proveedor de tratamiento](proveedor/README.md) |

Total: **73 pantallas y variantes**, con sus miniaturas. El inventario de Cliente incluye cinco pantallas de acceso común, compartidas por los cuatro roles, y el registro de cliente. No se duplican estos archivos en las demás carpetas.

**Disponible** significa que existe un PNG del diseño; **Pendiente** significa que no se identificó una pantalla independiente para esa vista. Estos prototipos no acreditan implementación ni aprobación de políticas, importes o integraciones.
